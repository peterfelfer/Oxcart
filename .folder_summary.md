## Context

This folder contains the hardware and design files for the Oxcart Titanium atom probe, an open-hardware straight flight path, microelectrode atom probe designed by Peter Felfer under his ERC starting grant. The system is controlled by the PyCCAPT software package and supports integration of Surface Concept and RoentDek detectors. The folder sits within the lab's instruments directory, serving as the central repository for build files and documentation for this custom-built instrument. The project is licensed under GPL, encouraging others to build their own versions or remix components. The current state is active, with known limitations being addressed: the piezo stage lacks lift force and is being replaced, and a stage re-design is underway to integrate a laser with in-situ dual-side focusing. The system achieves excellent vacuum (<10-11 mbar), minimal residual hydrogen, good mass resolution, and high detection efficiency, but has limited low-temperature capability (currently 35K) and only three pucks in the load lock.
